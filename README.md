# SolidWorks DXF Export

Первая версия: надстройка **DXF Export - Front View**, которая при включении переключает активную деталь или сборку на стандартный вид **Спереди**.

Экспорт DXF пока не реализован. Это первый шаг проекта.

## Поведение

- Запуск: включение надстройки в **Сервис → Добавления (Tools → Add-Ins)**.
- Поворот выполняется один раз при включении, для активной 3D-модели.
- Используется стандартный вид документа «Спереди», в том числе если пользователь ранее переопределил его.
- Масштаб сохраняется; геометрия и положение компонентов в сборке не изменяются. Автоматического сохранения нет.
- Если нет модели или открыт чертёж, появляется подсказка.
- Чтобы повторить действие, выключите надстройку, подтвердите закрытие окна добавлений, затем снова включите.
- Автоматический поворот при последующем открытии документов и отдельная кнопка пока отсутствуют. Для первого теста оставьте автозагрузку выключенной.

## Требования

Windows x64, установленный настольный SOLIDWORKS x64, Windows PowerShell 5.1 и .NET Framework 4.x.
Сборка использует компилятор .NET Framework и API-библиотеки вашей установки SOLIDWORKS. Visual Studio не требуется.
Регистрация COM-надстройки требует прав администратора.

## Установка

1. На странице репозитория нажмите **Code → Download ZIP**, распакуйте в постоянную папку, например `C:\SolidWorks-DXF-Export`.
2. Откройте Windows PowerShell в этой папке и соберите DLL:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
   ```

   Если SOLIDWORKS установлен в другую папку:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -SolidWorksDir "D:\SOLIDWORKS Corp\SOLIDWORKS"
   ```

   Скрипт ищет три DLL в `api\redist` и в корне указанной установки. При отсутствии сообщает имя файла.

3. Закройте SOLIDWORKS. Откройте **Windows PowerShell от имени администратора**, перейдите в папку проекта и выполните:

   ```powershell
   cd C:\SolidWorks-DXF-Export
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\register.ps1
   ```

   Параметр ExecutionPolicy действует только для запущенного процесса. RegAsm может предупредить, что сборка не имеет strong name: в этой локальной версии она регистрируется по постоянному пути через /codebase. Не перемещайте папку после регистрации.

4. Запустите SOLIDWORKS, откройте деталь или сборку и поверните её произвольно.
5. Откройте **Сервис → Добавления**, включите **DXF Export - Front View** в столбце активных добавлений. Модель должна перейти на вид спереди.

При обновлении сначала закройте SOLIDWORKS, выполните unregister.ps1, затем пересоберите и зарегистрируйте новую версию.

## Удаление

Закройте SOLIDWORKS и запустите из папки проекта в PowerShell от имени администратора:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\unregister.ps1
```

Затем можно удалить папку. Удаление записи автозагрузки применяется к текущему пользователю Windows; устанавливайте и удаляйте под одной учётной записью.

## Проверка на компьютере с SOLIDWORKS

- Деталь: включить надстройку при произвольном ракурсе — вид должен совпасть со стандартным «Спереди» (Ctrl+1).
- Сборка: тот же результат без изменения положения компонентов.
- Чертёж и отсутствие документов: подсказка, без ошибки или закрытия SOLIDWORKS.
- После ручного поворота выключить и включить надстройку: повторный переход на вид спереди.
- Перезапуск SOLIDWORKS с выключенной автозагрузкой: надстройка доступна в списке.
- Удаление: надстройка исчезает из списка после перезапуска.

Исходники подготовлены, но компиляция и запуск в SOLIDWORKS в среде разработки не выполнялись: здесь нет Windows, SOLIDWORKS и его API-библиотек. Готовая проверенная DLL пока не публикуется.

## Структура и API

- `src/FrontViewAddin.cs` — COM-надстройка, реализация ISwAddin, регистрация.
- `build.ps1` — сборка DLL и копирование зависимостей из локальной установки.
- `register.ps1`, `unregister.ps1` — установка и удаление.

Точки входа ISwAddin: [документация SOLIDWORKS](https://help.solidworks.com/2025/english/api/swpublishedapi/SolidWorks.Interop.swpublished~SolidWorks.Interop.swpublished.ISwAddin_members.html).
Поворот: `IModelDoc2.ShowNamedView2("", (int)swStandardViews_e.swFront)`, затем `GraphicsRedraw2()`.
