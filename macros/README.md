# Пакетный экспорт DXF из сборки

## Быстрый запуск

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте.
2. Откройте сборку в SOLIDWORKS в обычном режиме, с доступными деталями (не Large Design Review / SpeedPak). Выберите нужную конфигурацию сборки.
3. **Сервис → Макрос → Выполнить** → выберите **macros/Export_DXF_to_temp.swb**. В фильтре файлов включите SW Basic Macros (*.swb), если файл не виден.
4. Выберите папку для результатов. Отмена закрывает макрос без экспорта.
5. Дождитесь итогового окна. DXF, CSV с количеством и текстовый итог появятся в выбранной папке.

SOLIDWORKS преобразует SWB в SWP при запуске или редактировании. Полученную SWP-версию можно использовать для следующих запусков и назначить кнопке. Сохраняйте её в папке macros, чтобы не перепутать с первоначальным файлом в корне.

**Корневой Export_DXF_to_temp.swp — исходная присланная версия. Новый пакетный обход находится в macros/Export_DXF_to_temp.swb.** C#-надстройку устанавливать не требуется.

Запасной способ для существующего SWP: **Сервис → Макрос → Изменить**, откройте копию исходного SWP; в VBA-редакторе **File → Import File** импортируйте `ExportBatchDXF.bas`. Запускайте **ExportBatchDXF.main**. Старые модули с main не должны быть выбраны для кнопки запуска. При ошибке ссылки проверьте в **Tools → References** библиотеки SOLIDWORKS и SOLIDWORKS Constant type library своей версии. Сохраните SWP.

## Что выполняется

- Сначала макрос полностью обходит дерево активной конфигурации сборки, включая вложенные и повторно вставленные подсборки. Облегчённые компоненты пытается загрузить полностью; состояние загрузки после работы может остаться разрешённым.
- Уникальность: **полный путь SLDPRT + конфигурация, указанная у вхождения детали**. Одинаковые имена файлов из разных папок не объединяются. Для одного файла с двумя конфигурациями создаются две строки и два DXF.
- Количество — число вхождений этой пары во всей открытой сборке. Геометрически одинаковые отдельные файлы считаются разными деталями.
- Подавленные компоненты и содержимое подавленных подсборок исключаются. Скрытые компоненты учитываются. Исключение из спецификации не используется как фильтр.
- Для каждой уникальной пары деталь загружается/активируется, включается нужная конфигурация, затем вызывается экспорт. Используется логика предоставленного `ExportLayoutDXF`, перенесённая в один модуль: повторного запуска старого SWP и его диалогов нет.
- Листовая деталь с FlatPattern: развёртка, только геометрия, без линий сгиба.
- Обычная деталь: проекция текущего вида самой детали через временный чертёж, масштаб 1:1, миллиметры. Ориентация вхождения внутри сборки не используется. Для такой детали перед запуском задайте нужный вид в её документе, если он важен.
- Нужен существующий шаблон чертежа по умолчанию для нелистовых деталей. Либо задайте путь в константе `DRAWING_TEMPLATE`.
- Автоматическая раскладка на лист, удаление перекрывающихся контуров и проверка многотельных листовых деталей не реализованы.
- Виртуальные детали учитываются по доступному пути и конфигурации, но экспорт пропускается со статусом SKIPPED: сначала сохраните их во внешние файлы. Компоненты без доступной идентичности и нераскрытые подсборки перечисляются в итоговом TXT; количества при этом могут быть неполными.
- Макрос возвращает ранее загруженным деталям исходную активную конфигурацию и видимость, затем активирует исходную сборку. Исходные документы не сохраняет. Перестроение/временные виды могут установить признак изменения документа. Ошибки восстановления попадают в отчёт.
- Ошибка отдельной детали не останавливает остальные. Повреждённый или частично созданный DXF при ошибке может остаться в папке: используйте столбец Status, не только наличие файла.

Можно также запустить макрос из одной сохранённой детали: он экспортирует активную конфигурацию с количеством 1.

## Результаты

Файлы: `DXF_имя_детали__конфигурация.dxf`. Недопустимые символы заменяются, длинные имена сокращаются. При совпадении с существующим или уже запланированным файлом добавляется `__2`, `__3` и т. д.; существующие DXF не перезаписываются. Каждый повторный запуск создаёт новые файлы.

`DXF_report_дата_время.csv` — UTF-8 с BOM, разделитель `;`, открывается в Excel:

| Столбец | Содержимое |
|---|---|
| File | Полный путь исходной детали |
| Configuration | Конфигурация из сборки |
| Quantity | Количество вхождений |
| DXF | Запланированный путь результата |
| Status | OK, WARNING, ERROR или SKIPPED |
| Details | Ошибка, предупреждение экспорта или восстановления |

`DXF_summary_дата_время.txt` и итоговое окно показывают:

- Unique parts — число уникальных пар «файл + конфигурация»;
- Total part instances — суммарное количество вхождений;
- DXF exported — число успешных экспортов (включая WARNING);
- Failed / skipped — число невыгруженных уникальных позиций;
- Suppressed component nodes — число пропущенных узлов дерева, а не количество деталей внутри подавленных подсборок;
- Traversal / restore issues — проблемы обхода или восстановления состояния.

Интерфейс и заголовки отчёта на английском, чтобы текстовый SWB не зависел от кодовой страницы VBA; кириллица в путях и конфигурациях сохраняется в отчёте UTF-8.

## Проверка в SOLIDWORKS

В этой среде выполнена статическая проверка исходников, но нет SOLIDWORKS, поэтому компиляция VBA, преобразование SWB и реальный экспорт пока не проверены.

Для первого теста возьмите небольшую копию сборки:

| Сценарий | Ожидаемый результат |
|---|---|
| Деталь A, конфигурация X, три вхождения | Один DXF, Quantity = 3 |
| Та же A, конфигурация Y, два вхождения | Второй DXF, Quantity = 2; итого 2 уникальные позиции и 5 вхождений |
| Подсборка вставлена дважды; в каждой три A/X | Для A/X добавляется 6 вхождений |
| Две конфигурации подсборки с разным составом | Подсчёт по составу каждого конкретного вхождения |
| Подавленная A/X и скрытая A/X | Подавленная исключается, скрытая учитывается |
| Два разных пути к одноимённым SLDPRT | Разные позиции и разные имена DXF |
| Повторный запуск в ту же папку | Предыдущие файлы сохраняются, у новых появляется суффикс |
| Отсутствует шаблон для нелистовой детали | ERROR этой строки, обработка других продолжается |
| Виртуальная деталь / нераскрытая подсборка | SKIPPED / явное сообщение о неполноте обхода |
| Деталь была открыта в другой конфигурации | После экспорта исходная конфигурация восстановлена |

Проверьте известный размер и контуры в DXF, особенно для нелистовой или многотельной детали. Для диагностики ошибки нужны текст сообщения и соответствующая строка CSV; при ошибке компиляции — выделенная строка VBA.
